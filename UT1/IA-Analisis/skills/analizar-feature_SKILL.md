# Objetivo

Analizar una funcionalidad antes de realizar cambios.

# Procedimiento

1. Identifica claramente el requisito solicitado.
2. Examina la estructura actual del proyecto.
3. Busca modelos, migraciones, controladores, rutas, vistas, tests, factories y seeders.
4. Identifica funcionalidades similares.
5. Explica el flujo actual relacionado.
6. Identifica los archivos que probablemente deberán modificarse.
7. Propón una solución mínima.
8. Identifica riesgos o decisiones abiertas.

# Restricción

Durante esta Skill no se modificará ningún archivo.

# Salida esperada

## Requisito
## Situación actual
## Archivos encontrados
## Solución propuesta
## Archivos afectados
## Riesgos
## Pruebas necesarias
