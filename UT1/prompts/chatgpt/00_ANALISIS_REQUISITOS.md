# ChatGPT 00 — Análisis de requisitos

```text
Actúa como analista funcional.

Quiero desarrollar con Laravel un listado de productos de una tienda de informática.

Requisitos:

- SKU, nombre, categoría, descripción opcional, precio, stock y activo/inactivo;
- listado en /productos;
- búsqueda por nombre o SKU mediante q;
- filtro por categoría mediante categoria;
- orden inicial por nombre;
- mensaje cuando no hay resultados.

No escribas código.

Haz:

1. actores;
2. casos de uso;
3. reglas de negocio;
4. ambigüedades;
5. decisiones pendientes;
6. criterios de aceptación verificables;
7. separa requisitos explícitos de propuestas tuyas.

No añadas carrito, usuarios, pedidos o administración.
```
