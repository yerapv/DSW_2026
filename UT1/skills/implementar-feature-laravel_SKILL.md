1. crear o modificar migraciones;
2. crear o modificar Models;
3. crear Controllers;
4. crear Form Requests si son necesarios;
5. modificar rutas;
6. crear vistas Blade;

8. crear pruebas.

- Aplicar la solución mínima necesaria.

- No realizar refactorizaciones no relacionadas.
- No modificar código ajeno a la funcionalidad.
