# Procedimiento

1. Ejecutar git status --short.
2. Revisar git diff.
3. Ejecutar las pruebas específicas relacionadas.
4. Ejecutar php artisan test.
5. Ejecutar ./vendor/bin/pint --test.
6. Comprobar que no se han añadido credenciales, .env, temporales, logs o dependencias innecesarias.
7. Informar de los resultados.
